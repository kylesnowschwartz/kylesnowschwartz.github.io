Bumper Lanes

Guardrails for Claude Code sessions

$ claude plugins:add kylesnowschwartz/claude-bumper-lanes

What is this?

Bumper lanes prevent gutter balls. This plugin prevents runaway Claude Code sessions by tracking diffs and alerting you when changes exceed your comfort threshold.

Features

Diff Tracking

Monitor cumulative changes across your session in real-time.

Configurable Thresholds

Set your own limits for lines added, deleted, or modified.

Visual Feedback

See your diff budget at a glance with status line integration.
